`publication-links.json` is a curated presentation overlay keyed by existing work IDs. It preserves verified DOI, publisher, proceedings and repository destinations for records whose imported URL is Scopus. `reference` records the public bibliographic source used to identify the destination. Initial links were recovered from the owner's existing publication manifest using exact DBLP keys, with additional publisher/proceedings checks on 3 November 2026. Published versions take precedence over preprints when both are evidenced. Do not match generic titles such as “Preface”, or substitute a journal version for a separate conference abstract, solely on title similarity.
